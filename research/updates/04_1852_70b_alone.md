# Update 04 — 18:53 — can the 70B model decide alone?

## Tested (agent A, full run on all 221 labelled candidates)
Three prompt variants survived the 50-ruling pilot of eight: "strict" instructions with label first, the rubric in the prompt with label first, and the rubric with a rationale before the label. Thinking mode and the 8B model were piloted (agent report to follow).

## Learned
- The 70B model alone does not beat 11 deterministic features. It is about level with "submit all accident rulings".
- It leans towards yes: recall 0.88 to 0.92, but precision only 0.37 to 0.44.
- Inside each area it barely discriminates: ranking quality (AUC) is 0.53 to 0.60 within accident insurance and 0.59 to 0.67 within disability insurance, where 0.5 is chance. Its overall score mostly reflects "this is an accident-insurance case".
- Adding its score to the deterministic model changes nothing on held-out quarters.
- One useful point: at 90% recall the strict prompt needs 123 submissions against 134 for the deterministic model, so it carries a little independent signal at the high-recall end.
